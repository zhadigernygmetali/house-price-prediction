# House Price Prediction Using Linear Regression

## Project Overview
This beginner-friendly machine learning project demonstrates how to predict house prices based on property size using Python and Linear Regression.

The project uses a small fictional dataset of six houses to explore the basic machine learning workflow.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Project Steps
1. Create a dataset of fictional houses.
2. Explore the dataset and calculate basic statistics.
3. Visualize the relationship between house size and price.
4. Train a Linear Regression model.
5. Predict prices for new house sizes.
6. Evaluate the model using MAE, MSE, and R-squared.
7. Visualize actual and predicted prices.

## Key Findings
- Average house price: $296,666.67
- House prices range from $180,000 to $420,000.
- Each additional square foot increases the predicted price by $200 in this dataset.
- R-squared on training data: 1.0

## Example Predictions
| House Size | Predicted Price |
|---|---|
| 1,100 sq ft | $240,000 |
| 1,600 sq ft | $340,000 |
| 2,200 sq ft | $460,000 |

## Limitations
The dataset contains only six fictional houses, with prices following an exact linear pattern. The model uses only house size as a predictor and was evaluated on its training data. Therefore, its performance on real-world housing data is unknown.

## Conclusion
This project demonstrates fundamental machine learning concepts, including data exploration, visualization, model training, prediction, and evaluation.
